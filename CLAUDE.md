# Repository instructions

## Commit messages

- Write every Git commit message entirely in English, including the subject, body, and trailers.
- Use English Conventional Commit types and scopes when applicable, for example: `feat(mobile): add vehicle maintenance map`.
- Do not use Spanish words or phrases in commit messages. Keep product names, library names, and other proper nouns unchanged.
- Do not rewrite existing Git history solely to translate previous commit messages; apply this rule to all new commits.
